# PC 월별 전기 사용량 계산기

내 컴퓨터의 **부품과 최근 사용 기록을 자동으로 읽어서** 월별 전력 사용량(kWh)과
**한전 주택용 누진제 기준 전기요금**을 계산합니다.

## 실행 방법

### Windows 실행 파일 (Python 설치 불필요)
1. GitHub 저장소의 **Actions → Build Windows app** 에서 최근 실행을 엽니다.
2. 아래 **Artifacts** 의 `PCPowerCalc-windows` 를 내려받아 압축을 풉니다.
3. `PCPowerCalc.exe` 를 실행하면 자동 감지 후 결과가 바로 나옵니다.

직접 빌드하려면 Python 설치 후 `build.bat` 실행 → `dist\PCPowerCalc.exe`.

### Python으로 실행
```bash
python app.py                          # 화면 버전 (자동 감지)
python power_calc.py --auto            # 명령줄 버전 자동 감지
python power_calc.py --auto -k 300     # 집 사용량(컴퓨터 제외) 300kWh 기준
python power_calc.py -c example_pc.json
python power_calc.py --auto --save my_pc.json
```

## 자동으로 읽는 정보

| 항목 | Windows | Linux | macOS |
|---|---|---|---|
| CPU / GPU 모델 | ✅ | ✅ (`lspci`) | ✅ |
| RAM 개수·용량 | ✅ | 용량 (개수는 root 필요) | ✅ |
| SSD / HDD | ✅ | ✅ | 내장 SSD로 가정 |
| 모니터 개수·크기 | ✅ | ✅ (EDID) | 개수만 |
| 노트북 여부 | ✅ | ✅ | ✅ |
| 최근 30일 켜진 시간 | ✅ 이벤트 로그 (부팅·종료·절전) | ✅ `journalctl` (절전 구분 안 됨) | ❌ |

- 부품 소비전력은 모델 이름으로 **추정**합니다 (예: RTX 4070 → 최대 200W).
- 케이스 팬 개수, 게임·고부하 시간은 알아낼 수 없어서 기본값을 씁니다. 화면에서 고쳐주세요.

## 요금 계산 (한전 주택용 저압)

| 구간 (기타계절 / 7~8월) | 기본요금 | 전력량요금 |
|---|---|---|
| 200kWh 이하 / 300kWh 이하 | 910원 | 120.0원/kWh |
| 201~400 / 301~450kWh | 1,600원 | 214.6원/kWh |
| 400 초과 / 450 초과 | 7,300원 | 307.3원/kWh |

- 기후환경요금 9원/kWh, 연료비조정요금 +5원/kWh, 부가세 10%, 전력산업기반기금 2.7% 포함
- 누진제는 **집 전체 사용량**에 매겨지므로, "컴퓨터 뺀 우리 집 월 사용량"을 넣으면
  `PC 요금 = (집 전체 요금) − (컴퓨터 없을 때 요금)` 으로 컴퓨터 때문에 늘어나는 금액을 계산합니다.
- 복지·대가족 할인, 필수사용량 공제는 반영하지 않습니다.
- 요금표가 바뀌면 `tariff.py` 상단 숫자만 고치면 되고, 기후환경·연료비·기금은 화면에서도 바꿀 수 있습니다.

## 전력 계산 방식

- 가벼운 작업: `유휴 + (최대 − 유휴) × 0.2`, 고부하 작업: `유휴 + (최대 − 유휴) × 0.8`
- 본체 부품은 파워 효율(데스크톱 85%, 노트북 88%)로 나눠 콘센트 기준으로 환산, 모니터는 제외
- 꺼져 있는 시간·사용하지 않는 날은 대기전력만 계산
- 각 월의 실제 일수와 주당 사용 일수 반영

## 파일

| 파일 | 역할 |
|---|---|
| `app.py` | 화면 버전 (실행 파일의 시작점) |
| `power_calc.py` | 계산 로직 + 명령줄 버전 |
| `hardware.py` | 부품 감지 및 소비전력 추정 |
| `usage.py` | 사용 기록(켜진 시간) 감지 |
| `tariff.py` | 한전 누진제 요금표 |
