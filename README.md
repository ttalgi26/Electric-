# PC 월별 전기 사용량 계산기

내 컴퓨터의 **부품과 최근 사용 기록을 자동으로 읽어서** 월별 전력 사용량(kWh)과
**한전 주택용 누진제 기준 전기요금**을 계산합니다.

## 실행 방법

### Windows 실행 파일 (Python 설치 불필요)
1. GitHub 저장소의 **Actions → Build Windows app** 에서 최근 실행을 엽니다.
2. 아래 **Artifacts** 의 `PCPowerCalc-windows` 를 내려받아 압축을 풉니다.
3. `PCPowerCalc.exe` 를 실행하면 자동 감지 후 결과가 바로 나옵니다.

직접 빌드하려면 Python 설치 후 `build.bat` 실행 → `dist\PCPowerCalc.exe`.

### Python으로 실행
```bash
python app.py                          # 화면 버전 (자동 감지)
python power_calc.py --auto            # 명령줄 버전 자동 감지
python power_calc.py --auto -k 300     # 집 사용량(컴퓨터 제외) 300kWh 기준
python power_calc.py -c example_pc.json
python power_calc.py --auto --save my_pc.json
python measure.py                      # 내장 부하 테스트 (각 20초)
python measure.py --custom 게임 --seconds 120   # 게임 등 직접 실행하며 측정
```

## 자동으로 읽는 정보

| 항목 | Windows | Linux | macOS |
|---|---|---|---|
| CPU / GPU 모델 | ✅ | ✅ (`lspci`) | ✅ |
| RAM 개수·용량 | ✅ | 용량 (개수는 root 필요) | ✅ |
| SSD / HDD | ✅ | ✅ | 내장 SSD로 가정 |
| 모니터 이름·크기·해상도·주사율 | ✅ (내장 화면은 밝기도) | ✅ EDID (주사율은 60Hz로 가정) | 이름·해상도·주사율 |
| 노트북 여부 | ✅ | ✅ | ✅ |
| 최근 30일 켜진 시간 | ✅ 이벤트 로그 (부팅·종료·절전) | ✅ `journalctl` (절전 구분 안 됨) | ❌ |

- 부품 소비전력은 모델 이름으로 **추정**합니다 (예: RTX 4070 → 최대 200W).
- 케이스 팬 개수, 게임·고부하 시간은 알아낼 수 없어서 기본값을 씁니다. 화면에서 고쳐주세요.

## 모니터 전력 ("모니터" 탭)

크기·해상도(화면비)·주사율·패널(LCD / OLED / 미니 LED)·밝기·HDR로 계산합니다.

- 켜짐 전력 = 회로 5W (+120Hz 이상 3W, +200Hz 이상 3W, +4K 2W) + 화면 면적 × 0.085W/in² × 밝기 계수
- 밝기 계수: LCD `0.2 + 0.8 × 밝기`, OLED `0.9 × 밝기`, 미니 LED는 LCD × 1.2, HDR은 × 1.3
- 예: 24" FHD 60Hz 밝기 70% ≈ 21W, 27" QHD 144Hz ≈ 28W, 34" 울트라와이드 밝기 100% ≈ 43W
- PC 사용 중 화면이 꺼져 있는 비율("모니터 켜짐 비율")과 대기전력(대당 0.3W)도 반영
- 선택한 모니터의 밝기별(100~20%) 월 사용량·요금 비교표 제공

## 전력 테스트 ("전력 테스트" 탭 / `measure.py`)

1. **자동 부하 테스트**: 유휴, CPU 1코어·절반·전체, 메모리 복사, 디스크 읽기/쓰기를 차례로 실행하며 측정
2. **직접 측정**: 게임·영상·웹서핑 등 원하는 프로그램을 쓰는 동안 측정 (이름과 시간 지정)
3. 결과마다 **하루 시간**을 입력하면 월 사용량·요금 계산 → "월별 계산 적용"으로 메인 계산에 반영

측정 방식 (있는 센서는 실측, 없으면 사용률 × 부품 전력으로 추정):

| 항목 | Windows | Linux |
|---|---|---|
| CPU 사용률 | 성능 카운터 (% Processor Utility) | /proc/stat |
| CPU 전력 | 추정 | **실측** RAPL (root 권한 필요) |
| GPU 사용률 | GPU 엔진 카운터 / nvidia-smi | nvidia-smi / AMD sysfs |
| GPU 전력 | **실측** NVIDIA (nvidia-smi) | **실측** NVIDIA / AMD |
| 시스템 전체 | **실측** 노트북 배터리 방전 (전원선 뽑았을 때) | **실측** 배터리 방전 |

GPU는 이 프로그램이 직접 부하를 걸 수 없으므로 게임 등을 "직접 측정"으로 재야 합니다.
가장 정확한 값은 콘센트형 전력 측정기입니다. 이 결과와 비교해 부품 전력을 조정해 보세요.

## 요금 계산 (한전 주택용 저압)

| 구간 (기타계절 / 7~8월) | 기본요금 | 전력량요금 |
|---|---|---|
| 200kWh 이하 / 300kWh 이하 | 910원 | 120.0원/kWh |
| 201~400 / 301~450kWh | 1,600원 | 214.6원/kWh |
| 400 초과 / 450 초과 | 7,300원 | 307.3원/kWh |

- 기후환경요금 9원/kWh, 연료비조정요금 +5원/kWh, 부가세 10%, 전력산업기반기금 2.7% 포함
- 누진제는 **집 전체 사용량**에 매겨지므로, "컴퓨터 뺀 우리 집 월 사용량"을 넣으면
  `PC 요금 = (집 전체 요금) − (컴퓨터 없을 때 요금)` 으로 컴퓨터 때문에 늘어나는 금액을 계산합니다.
- 복지·대가족 할인, 필수사용량 공제는 반영하지 않습니다.
- 요금표가 바뀌면 `tariff.py` 상단 숫자만 고치면 되고, 기후환경·연료비·기금은 화면에서도 바꿀 수 있습니다.

## 전력 계산 방식

- 가벼운 작업: `유휴 + (최대 − 유휴) × 0.2`, 고부하 작업: `유휴 + (최대 − 유휴) × 0.8`
- 본체 부품은 파워 효율(데스크톱 85%, 노트북 88%)로 나눠 콘센트 기준으로 환산 (모니터는 별도 계산)
- 전력 테스트 시간표를 적용하면: 활동별 측정 전력 × 하루 시간 + 나머지 시간 대기전력
- 꺼져 있는 시간·사용하지 않는 날은 대기전력만 계산
- 각 월의 실제 일수와 주당 사용 일수 반영
